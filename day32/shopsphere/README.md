# ShopSphere — React E-Commerce Application

ShopSphere is a modern, React-based e-commerce front-end application. It allows users to browse products, filter by categories, view detailed product information, and manage a shopping cart without traditional page reloads.

This project was built from scratch to demonstrate advanced React concepts, including component composition, dynamic routing, side effects, and global state management.

## ✨ Key Features

* **Multi-Page SPA Experience:** Seamless, instant navigation using React Router.
* **Product Catalog:** Fetches and displays real-world products dynamically using the DummyJSON API.
* **Advanced Filtering & Sorting:** Users can search by keyword, filter by category, and sort by price (Low to High / High to Low) simultaneously.
* **Dynamic Routing:** Unique URLs for individual product detail pages (e.g., `/products/:id`) built with `useParams`.
* **Global Shopping Cart:** Cart state (adding, removing, and total calculation) is managed across the entire application using the React Context API.
* **Responsive Layout:** Clean CSS layout featuring a Home page with promotional sections, a Category browsing grid, and reusable product cards.
* **Error Handling:** Custom 404 page for invalid routes and graceful API error/loading states.

## 🛠️ Technologies Used

* **React 18** (Functional Components, Hooks: `useState`, `useEffect`)
* **React Router DOM** (Client-side Routing, `useLocation`, `useParams`)
* **Context API** (Global State Management)
* **Vite** (Build Tool & Development Server)
* **Vanilla CSS** (Flexbox & CSS Grid)
* **Netlify** (Hosting & Deployment)
